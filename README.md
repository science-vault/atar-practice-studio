# ATAR Practice Studio

Standalone ATAR science practice website, independent of Science Vault.

## Features
- Five subjects and 12 original sample questions
- Multiple-choice marking from answer keys and worked explanations
- No AI services, API keys or paid dependencies
- Subject, year and topic filters; bookmarks; progress and study streaks
- Progress saved in each visitor’s browser, without accounts or server storage

## GitHub Pages
Deploy from the `main` branch and `/ (root)` folder. No build step is required. Open `index.html` locally for development.

Browser progress is specific to each device and website origin and does not transfer from other hosted versions.
